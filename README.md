# Bazel by Example: C/C++

Bazel is a build system that can be used for anything from simple open source libraries to large multi-language, multi-platform projects. This guide is a collection of self-contained and runnable examples that demonstrate Bazel concepts specifically for C and C++ developers. Follow along by cloning the repo locally (don't worry, you don't need to have anything installed other than git!) or opening the branch in a [Codespace](https://github.com/features/codespaces) by clicking `Code` -> `Codespaces` -> `Create codespace on <branch name>` above.

Don't forget to check out the [official documentation](https://bazel.build/docs) for deeper insights.

Let's get started!
